# CardForge

CardForge 是一个手机竖屏优先、可持续加入新玩法的卡牌游戏平台。当前版本包含统一游戏大厅、游戏注册与按需加载机制、隔离失败的游戏宿主、无规则假设的共享能力，以及三款规则完全独立的可玩游戏。

- 「烬契」：原创 2v2 回合对战，包含四套非对称牌组、角色被动、状态、评分式 AI 和回合末过载。
- 「二十一刻」：轻量 21 点，包含独立牌靴、Ace 计分、要牌/停牌、庄家流程与完整结算。
- 「掼蛋 · 入门局」：双副牌四人对家，包含牌型比较、红心级牌百搭、清墩、组队胜负与托管 AI。

三个游戏不共享 `GameState`、回合或卡牌规则，只通过平台的最小运行契约注册和加载。

## 运行

```bash
npm install
npm run dev
```

可用 `?game=<game-id>` 直接打开可玩牌桌，例如 `?game=guandan`。从大厅进入游戏后，浏览器返回键会回到大厅；无效或仍在筹备的 ID 不会进入游戏宿主。

验证命令：

```bash
npm run typecheck
npm test
npm run build
```

## 项目结构

```text
src/
  app/                    # 平台大厅与游戏装载入口
  core/games/             # 游戏清单、注册表、最小运行契约
  shared/                 # 无玩法规则的卡牌视觉、声音、焦点与基础身份类型
  games/
    registry.ts           # 平台唯一的游戏登记处
    ember-pact/           # 独立 Demo：规则、数据、AI、组件与样式
      domain/             # 可单测的纯规则层
      components/         # 只属于该游戏的表现组件
    twenty-one/           # 独立点数游戏：规则、庄家流程、牌面与样式
      domain/             # 52 张牌、计分与结算纯函数
      components/         # 只属于该游戏的标准牌面
    guandan/              # 独立四人对家游戏：牌型、回合、AI 与样式
      domain/             # 双副牌、百搭、跟牌、清墩与胜负纯函数
      components/         # 适配 27 张手牌的紧凑牌面
```

核心层不包含 HP、攻击、阵营、点数、牌型或传统回合阶段。它只负责“有哪些游戏”和“如何加载游戏”。三款游戏中的玩法概念全部保留在各自模块内。

更详细的依赖边界和新增游戏步骤见 [docs/architecture.md](docs/architecture.md)。
